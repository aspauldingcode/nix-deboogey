nix-deboogey

Declarative Tart VMs with Deboogey already installed. Pull a prebuilt, or let nix-darwin clone it for you.

How it works

  1. Packer clones a Cirrus Labs macos-<name>-vanilla image.
  2. Inside that guest it checks the macOS major version, disables SIP, installs Deboogey, then installs a tweak loader: Ammonia on Monterey through Sequoia, Plugin Playground on Tahoe and Golden Gate.
  3. CI pushes that VM to GitHub Packages as ghcr.io/aspauldingcode/nix-deboogey/macos-<name>-deboogey:latest.
  4. You set nix-deboogey.vms.<name>.enable = true. darwin-rebuild switch installs Tart and clones that image.

SIP and the -arm64e_preview_abi boot arg are applied in the guest. The host Mac is left alone. The guest login is admin / admin. These VMs run on Apple Silicon.

Declare it

Add the input and the module. enable = true is the install switch. darwin-rebuild switch installs Tart, pulls the CI image, and clones a local VM named <name>-deboogey.

{
  inputs.nix-deboogey.url = "github:aspauldingcode/nix-deboogey";

  outputs = { self, nix-darwin, nix-deboogey, ... }: {
    darwinConfigurations.mac = nix-darwin.lib.darwinSystem {
      system = "aarch64-darwin";
      modules = [
        nix-deboogey.darwinModules.default
        {
          nix-deboogey.vms.tahoe.enable = true;
          nix-deboogey.vms.ventura = {
            enable = true;
            cpu = 6;
            memory = 12;    # GiB
            diskSize = 80;  # GiB
            autoStart = true;
          };
        }
      ];
    };
  };
}

The same option exists for golden-gate, sequoia, sonoma, and monterey. autoStart defaults to false, so the VM is installed and stopped until you run it. Guest login is admin / admin.

tart run tahoe-deboogey
tart-ssh tahoe-deboogey
OptionDefaultMeaning
vms.<name>.enablefalseInstall this prebuilt on darwin-rebuild switch.
vms.<name>.cpu4CPU count.
vms.<name>.memory8Memory in GiB.
vms.<name>.diskSize50Disk in GiB. A smaller value leaves the disk as it is.
vms.<name>.autoStartfalseStart the VM at login and share your home directory.

Run one without nix-darwin

nix run brings Tart with it, pulls the same CI image, clones a temporary VM, and deletes it on exit. The VM window opens by default. Pass --headless to skip the window, or --no-home to skip the home share.

nix run github:aspauldingcode/nix-deboogey#ventura
nix run github:aspauldingcode/nix-deboogey#tahoe -- --headless
