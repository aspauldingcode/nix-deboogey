nix-deboogey

Declarative Tart VMs with Deboogey already installed. Pull a prebuilt, or let nix-darwin clone it for you.

How it works

  1. Packer clones a Cirrus Labs macos-<name>-vanilla image.
  2. Inside that guest it checks the macOS major version, disables SIP, installs Deboogey, then installs a tweak loader: Ammonia on Monterey through Sequoia, Plugin Playground on Tahoe and Golden Gate.
  3. The finished VM is pushed to GitHub Packages as ghcr.io/aspauldingcode/nix-deboogey/macos-<name>-deboogey:latest.
  4. You either nix run a throwaway clone, or list the name in nix-deboogey.tart.vms so nix-darwin pulls and clones it on darwin-rebuild switch.

SIP and the -arm64e_preview_abi boot arg are applied in the guest. The host Mac is left alone. The guest login is admin / admin. These VMs run on Apple Silicon.

Use it

Each command pulls the image, clones a temporary VM, and deletes that clone on exit. Add --gui for a window. Add --no-home to skip sharing your home directory over VirtioFS.

nix run github:aspauldingcode/nix-deboogey#tahoe -- --gui
nix run github:aspauldingcode/nix-deboogey#ventura
nix run github:aspauldingcode/nix-deboogey#sequoia
nix run github:aspauldingcode/nix-deboogey            # Sequoia

The app names are golden-gate, tahoe, sequoia, sonoma, ventura, and monterey. ephemeral-tahoe is the same app as tahoe.

Tart has to be on the host. The nix-darwin module installs it from the Cirrus Homebrew tap. For a one-off run, install it yourself:

brew install cirruslabs/cli/tart

Declare it

Add the flake and the module. A string is enough. The image name drops a leading macos-, and the local Tart VM is named <name>-deboogey.

{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixpkgs-unstable";
    nix-darwin.url = "github:LnL7/nix-darwin";
    nix-darwin.inputs.nixpkgs.follows = "nixpkgs";
    nix-deboogey.url = "github:aspauldingcode/nix-deboogey";
  };

  outputs = { self, nixpkgs, nix-darwin, nix-deboogey, ... }: {
    darwinConfigurations."my-mac" = nix-darwin.lib.darwinSystem {
      system = "aarch64-darwin";
      modules = [
        nix-deboogey.darwinModules.default
        {
          nix-deboogey.tart.vms = [
            "sequoia"
            "tahoe"
            {
              name = "ventura";
              cpu = 6;
              memory = 12;   # gigabytes
              diskSize = 80; # gigabytes
              headless = true;
              autoStart = true;
            }
          ];
        }
      ];
    };
  };
}

darwin-rebuild switch pulls the image when autoPull is true (the default), clones it if the local name is missing, and sets CPU, memory, and disk. autoStart defaults to false, so the VM stays stopped until you run it:

tart run sequoia-deboogey
tart-ssh sequoia-deboogey
tart-ssh sequoia-deboogey uname -a

tart-ssh and tart-scp are shell functions from the module. They use the guest admin password. If the declared name is macos-sequoia, the local VM is macos-sequoia-deboogey and the image is still the Sequoia prebuilt.

What you can set

OptionDefaultMeaning
tart.enabletrueInstall Tart and manage the VM list.
tart.autoPulltruePull each image during activation.
tart.defaults.cpu4Default CPU count.
tart.defaults.memory8Default memory in gigabytes.
tart.defaults.diskSize50Default disk in gigabytes. Activation only grows a disk.
vms.*.sourcethe GHCR prebuiltOCI image to clone.
vms.*.netsharedshared, bridged, host-only, or softnet.
vms.*.enableHomeSharetrueShare the host home directory as home.
vms.*.headlessfalsePass --no-graphics when the launchd agent starts the VM.
vms.*.autoStartfalseStart the VM at login via launchd.
orchard.enablefalseAlso run an Orchard user agent.
